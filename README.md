# Jiehang Zhong — Personal Homepage

Static GitHub Pages site for `https://JiehangZhong.github.io/`.

## Publish

1. Create a public GitHub repository named `JiehangZhong.github.io` under the `JiehangZhong` account.
2. Put the files in this folder at the repository root and push them to the `main` branch.
3. In the repository, open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/ (root)`.

GitHub Pages will publish the site at `https://JiehangZhong.github.io/` after the first deployment completes.
